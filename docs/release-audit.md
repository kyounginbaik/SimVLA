# Open-source readiness audit

Snapshot: 2026-10-07. This audit combines local evidence with the public release-candidate CI run; it is not unaffiliated external replication. Rows include historical checks; current bounded collection references cover kitchen 813, seed 0 for all three robots. `Pass` means only the stated check is satisfied. Severity is P0 (blocks the stated use), P1 (important), or P2 (polish).

The CPU package and GPU research workflows have separate release boundaries. A GPU or AI Worker
P0 blocks that named simulator use case; it does not block publishing the independently usable
CPU package. The remaining CPU package publication blockers are a published release and immutable
release evidence (F097, F099), and private maintainer channels (F085, F090). The asset inventory and
project-controlled permissions are recorded in F089; upstream terms still apply.
The other GPU failures describe experimental capabilities that must stay qualified until their
assets, clean installation, and end-to-end results are public.

drop confirmed a collision surface over the basin. A stage-local repair passed
the drop test. RB-Y1 collection 2437107 and action-only replay 2437144 passed the
stricter below-rim gate and SimVQA validation. AI Worker collection 2436991 passed,
but its loaded-home replays 2437146 and 2437202 failed; that chain remains experimental.

12 physics substeps and one accepted episode; see
[its dated evidence](evidence/aiworker-loaded-home-physics12-2026-10-07.json).
It supersedes the earlier replay failures for this exact profile and seed only.

The clean release-commit source gate passed 816 tests with four skips on Python 3.10 and
757 tests with 27 skips on Python 3.11 and 3.12. Installed wheels on Python 3.11/3.12
passed `pip check`, the CPU demo, and task-template validation. Wheel/sdist build,
Twine metadata, distribution-scope, checksum, clean-source provenance, and 189 extracted
sdist tests passed. Earlier isolated offline-export, sink/USD and browser results remain
separate targeted checks.

Fresh public-runtime chains have bounded passes for Anubis (2426755 → 2429275),
RB-Y1 (latest batch 2437751 → 2437810/11/12), and AI Worker (extended carry
2436772 → 2437094; loaded-home physics-12 2437904 → 2437908). AI Worker uses
hybrid motor/contact replay and recorded prelude state; the older extended-carry
pass also used 0.9 seconds extra settling. Basin claims apply only to the repaired
gate and named references. Failures remain in `docs/validation.md`; these are not
universal reliability claims.
The public release-candidate code passed hosted CI; a reviewed final commit,
versioned publication, and unaffiliated replication remain separate steps.
